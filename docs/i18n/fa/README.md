# Open VSC Claude

[English](../../../README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · [繁體中文（台灣）](../zh-TW/README.md) · [한국어](../ko/README.md) · [Русский](../ru/README.md) · [Українська](../uk/README.md) · [Deutsch](../de/README.md) · [Italiano](../it/README.md) · [Français](../fr/README.md) · [العربية](../ar/README.md) · [فارسی](../fa/README.md)

افزونهٔ VS Code: یک پشتهٔ زبان/چارچوب انتخاب کنید، کد تولیدشده را ببینید، با Claude بهبودش دهید و به‌عنوان پروژه ذخیره کنید.

- نسخهٔ نمایشی آنلاین: https://easy-web.tokyo/open-vps-claude/
- کد منبع: https://github.com/aon-co-jp/open-vsc-claude
- مجوز: MIT

## امکانات

- انتخاب رویکرد: GraphQL + WunderGraph Cosmo (بدون Node.js و REST)، یا TypeScript + Node.js + REST، یا توصیف هر پشته‌ای با زبان خودتان.
- انتخاب فرانت‌اند (HTML5+CSS3+JS، Rust+Leptos آزمایشی، TypeScript، React)، پایگاه داده (هیچ / SQLite / PostgreSQL)، دروازه (Cosmo Router / RPoem / هیچ) و بک‌اند (Python+FastAPI، Rust+Poem، Node.js+Express).
- پیش‌نمایش همهٔ فایل‌های تولیدشده با شمارهٔ خط؛ کپی یا بازکردن در ویرایشگر. با تغییر انتخاب، پیش‌نمایش بلافاصله به‌روز می‌شود.
- «تولید/بهبود با Claude» پروژه را بر اساس درخواست شما ویرایش می‌کند (کلید Anthropic API لازم است).
- ذخیره در پوشه (با تأیید جایگزینی) یا دانلود zip در نسخهٔ نمایشی مرورگر.
- رابط و هشدارها به انگلیسی، ژاپنی، چینی (ساده/سنتی) و کره‌ای؛ بررسی به‌روزرسانی برای نصب دستی.

## سکوهای پشتیبانی‌شده

یک بستهٔ خالص JavaScript، بدون کد بومی.

| سکو | نحوهٔ استفاده |
| --- | --- |
| Windows / macOS / Linux | افزونهٔ VS Code (دسکتاپ) |
| Android (phone, tablet) / iPhone / iPad | VS Code در مرورگر (vscode.dev / github.dev) با افزونهٔ وب، یا نسخهٔ نمایشی مرورگر که به صفحهٔ اصلی اضافه شده است (PWA، بدون اینترنت هم کار می‌کند) |
| * | نسخهٔ نمایشی آنلاین: https://easy-web.tokyo/open-vps-claude/ |

## نحوهٔ استفاده

1. در پالت فرمان، «Open VSC Claude: Open Stack Picker» را اجرا کنید.
2. پشته را انتخاب کنید؛ پیش‌نمایش بلافاصله به‌روز می‌شود.
3. برای تولید با Claude، کلید API را بارگذاری کنید («Load Anthropic API Key from a .txt file») و Ctrl+Enter را بزنید.

## هشدارها

- کد تولیدشده نقطهٔ شروع است؛ پیش از استفاده در محیط واقعی آن را بررسی، آزمایش و ایمن کنید. بدون هیچ ضمانتی.
- تولید با Claude پشتهٔ انتخابی، فایل‌ها و درخواست شما را به Anthropic API می‌فرستد؛ رمز و داده‌های شخصی وارد نکنید.
- کلیدهای API، توکن‌ها و کلیدهای خصوصی SSH را در یک فایل .txt محلی بیرون از هر مخزن نگه دارید؛ هرگز کامیت نکنید و در گفتگو نچسبانید.
- دروازهٔ RPoem فقط بر اساس فیلد ریشه مسیریابی می‌کند (پرس‌وجوهایی که چند زیرگراف را ترکیب کنند رد می‌شوند)؛ Rust + Leptos آزمایشی است.
- متن کامل هشدارها به پنج زبان در پنجرهٔ انتخاب و در README افزونه نمایش داده می‌شود.
