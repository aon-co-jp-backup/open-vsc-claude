# PORTING.md — Open VSC Claude

یادداشت‌های تحویل: آنچه انجام شده، آنچه نشده، دام‌ها و روش‌ها.

## انجام‌شده

- افزونه: انتخاب پشته، تولید با Claude، حالت ورودی آزاد، بررسی به‌روزرسانی.
- دروازهٔ RPoem با انتقال به زیرگراف‌ها (مخزن جداگانهٔ RPoem، کامیت babc658).
- نسخهٔ نمایشی مرورگر + PWA در easy-web.tokyo/open-vps-claude.
- مستندات به ۱۲ زبان.

## باقی‌مانده

- انتشار در VS Code Marketplace / Open VSX (حساب مالک و توکن لازم است؛ PUBLISHING.md را ببینید).
- اجرای واقعی Cosmo Router (روی رایانهٔ توسعه نه فایل اجرایی هست و نه Docker).
- آزمایش حالت ورودی آزاد با کلید واقعی Anthropic API.
- آزمایش روی دستگاه‌های واقعی iPhone، iPad و Android.
- بازبینی ترجمه‌ها توسط افراد بومی‌زبان.

## دام‌ها

- فایل‌ها ممکن است CRLF باشند و جایگزینی با اسکریپت بی‌صدا شکست بخورد. از ابزارهای ویرایشگر استفاده کنید.
- نشانه‌گذاری گریز در heredoc پوسته، \n را به خط جدید واقعی تبدیل می‌کند؛ اسکریپت‌های کمکی را ابتدا در فایل بنویسید.
- مرورگر داخلی برنامه Service Worker را مسدود می‌کند؛ PWA را با Chromium بدون رابط (playwright همراه @vscode/test-web) آزمایش کنید.
- در مخزن‌هایی که تاریخچه‌شان بازنویسی شده هرگز git pull اجرا نکنید (مخزن فراداده را ببینید).
- نام مخزن open-vsc-claude است؛ مسیر نسخهٔ نمایشی که مالک خواسته /open-vps-claude است.

## روش انتشار

1. آزمون‌ها را اجرا کنید (compile، test، test:vscode، test:web).
2. نسخه را در package.json افزایش دهید و npm run package را اجرا کنید.
3. gh release create vX.Y.Z را با فایل .vsix و .sha256 آن اجرا کنید (به‌روزرسانی جمع‌کنترلی را بررسی می‌کند).
4. npm run build:demo را اجرا و سپس webpage/ را روی VPS مستقر کنید.
