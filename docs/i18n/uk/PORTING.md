## Підводні камені

- Файли можуть бути в CRLF; заміна скриптом може мовчки не спрацювати. Віддавайте перевагу інструментам редактора.
- Екранування в heredoc оболонки перетворює \n на справжні переходи рядка; спершу записуйте допоміжні скрипти у файли.
- Вбудований браузер блокує Service Worker; перевіряйте PWA в headless Chromium (playwright із @vscode/test-web).
- Не виконуйте git pull у репозиторіях із переписаною історією (див. мета-репозиторій).
- Репозиторій називається open-vsc-claude; шлях демо, який задав власник, — /open-vps-claude.

## Порядок випуску

1. Запустіть тести (compile, test, test:vscode, test:web).
2. Підвищте версію в package.json і виконайте npm run package.
3. gh release create vX.Y.Z з файлами .vsix і .sha256 (оновлення перевіряє контрольну суму).
4. npm run build:demo, потім розмістіть webpage/ на VPS.
