# Open VSC Claude

[English](../../../README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · [繁體中文（台灣）](../zh-TW/README.md) · [한국어](../ko/README.md) · [Русский](../ru/README.md) · [Українська](../uk/README.md) · [Deutsch](../de/README.md) · [Italiano](../it/README.md) · [Français](../fr/README.md) · [العربية](../ar/README.md) · [فارسی](../fa/README.md)

Розширення VS Code: оберіть стек мови та фреймворку, перегляньте згенерований код, доопрацюйте його за допомогою Claude і збережіть як проєкт.

- Онлайн-демо: https://easy-web.tokyo/open-vps-claude/
- Вихідний код: https://github.com/aon-co-jp/open-vsc-claude
- Ліцензія: MIT

## Можливості

- Вибір підходу: GraphQL + WunderGraph Cosmo (без Node.js і REST), TypeScript + Node.js + REST або будь-який стек, описаний власними словами.
- Вибір фронтенду (HTML5+CSS3+JS, експериментальний Rust+Leptos, TypeScript, React), БД (немає / SQLite / PostgreSQL), шлюзу (Cosmo Router / RPoem / немає) та бекенду (Python+FastAPI, Rust+Poem, Node.js+Express).
- Перегляд усіх згенерованих файлів із номерами рядків; копіювання або відкриття в редакторі. Зміна вибору миттєво оновлює перегляд.
- «Згенерувати / доопрацювати з Claude» редагує проєкт за вашим запитом (потрібен ключ Anthropic API).
- Збереження в теку (з підтвердженням перезапису) або, у браузерній демо, завантаження zip.
- Інтерфейс і примітки англійською, японською, китайською (спрощеною/традиційною) та корейською; перевірка оновлень для ручного встановлення.

## Підтримувані платформи

Один чисто JavaScript-пакет, без нативного коду.

| Платформа | Як користуватися |
| --- | --- |
| Windows / macOS / Linux | Розширення VS Code (настільне) |
| Android (phone, tablet) / iPhone / iPad | VS Code у браузері (vscode.dev / github.dev) з веб-розширенням або браузерна демо на головному екрані (PWA, працює офлайн) |
| * | Онлайн-демо: https://easy-web.tokyo/open-vps-claude/ |

## Використання

1. Виконайте «Open VSC Claude: Open Stack Picker» у палітрі команд.
2. Оберіть стек — перегляд оновиться одразу.
3. Для генерації з Claude завантажте ключ API («Load Anthropic API Key from a .txt file») і натисніть Ctrl+Enter.

## Примітки

- Згенерований код — це відправна точка; перед використанням у продакшені перевірте, протестуйте та захистіть його. Без гарантій.
- Генерація з Claude надсилає обраний стек, файли та запит до Anthropic API; не додавайте секрети й персональні дані.
- Ключі API, токени та приватні ключі SSH зберігайте в локальному .txt поза репозиторієм; не комітьте й не вставляйте їх у чат.
- Шлюз RPoem маршрутизує лише за кореневими полями (запити, що поєднують підграфи, відхиляються); Rust + Leptos — експериментально.
- Повний текст приміток п’ятьма мовами показано у вікні вибору та в README розширення.
