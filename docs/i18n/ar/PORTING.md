# PORTING.md — Open VSC Claude

ملاحظات التسليم: ما أُنجز وما لم يُنجز والمزالق والإجراءات.

## أُنجز

- الإضافة: اختيار الحزمة، التوليد باستخدام Claude، وضع الإدخال الحر، فحص التحديثات.
- بوابة RPoem مع التمرير إلى الرسوم الفرعية (مستودع RPoem المنفصل، الإيداع babc658).
- العرض التجريبي + PWA على easy-web.tokyo/open-vps-claude.
- وثائق بـ 12 لغة.

## المتبقي

- النشر في VS Code Marketplace / Open VSX (يلزم حساب المالك ورمز الوصول؛ انظر PUBLISHING.md).
- تشغيل Cosmo Router فعليًا (لا يوجد ملف تنفيذي ولا Docker على حاسوب التطوير).
- اختبار وضع الإدخال الحر بمفتاح Anthropic API حقيقي.
- الاختبار على أجهزة iPhone وiPad وAndroid حقيقية.
- مراجعة الترجمات من قِبل متحدثين أصليين.

## المزالق

- قد تستخدم الملفات CRLF، وقد يفشل الاستبدال البرمجي بصمت. فضّل أدوات المحرر.
- تحويل الهروب داخل heredoc في الصدفة يجعل \n أسطرًا جديدة فعلية؛ اكتب السكربتات المساعدة في ملفات أولًا.
- المتصفح المدمج يحجب Service Worker؛ اختبر PWA بـ Chromium بلا واجهة (playwright ضمن @vscode/test-web).
- لا تشغّل git pull في المستودعات التي أُعيدت كتابة سجلها (انظر المستودع الفوقي).
- اسم المستودع open-vsc-claude؛ ومسار العرض التجريبي الذي طلبه المالك هو /open-vps-claude.

## إجراء الإصدار

1. شغّل الاختبارات (compile وtest وtest:vscode وtest:web).
2. ارفع الإصدار في package.json ونفّذ npm run package.
3. نفّذ gh release create vX.Y.Z مع ملف .vsix وملف .sha256 (يتحقق التحديث من المجموع الاختباري).
4. نفّذ npm run build:demo ثم انشر webpage/ على VPS.
