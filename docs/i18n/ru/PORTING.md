# PORTING.md — Open VSC Claude

Заметки для передачи работы: что сделано, что нет, подводные камни и процедуры.

## Сделано

- Расширение: выбор стека, генерация Claude, режим свободного ввода, проверка обновлений.
- Шлюз RPoem с пересылкой в подграфы (отдельный репозиторий RPoem, коммит babc658).
- Браузерная демо + PWA на easy-web.tokyo/open-vps-claude.
- Документация на 12 языках.

## Предстоит

- Публикация в VS Code Marketplace / Open VSX (нужны аккаунт владельца и токен; см. PUBLISHING.md).
- Реальный запуск Cosmo Router (на машине разработки нет ни бинарного файла, ни Docker).
- Проверка режима свободного ввода с реальным ключом Anthropic API.
- Проверка на реальных iPhone, iPad и Android.
- Вычитка переводов носителями языка.

## Подводные камни

- Файлы могут быть в CRLF; замена скриптом может молча не сработать. Предпочитайте инструменты редактора.
- Экранирование в heredoc оболочки превращает \n в настоящие переводы строк; сначала записывайте вспомогательные скрипты в файлы.
- Встроенный браузер блокирует Service Worker; проверяйте PWA в headless Chromium (playwright из @vscode/test-web).
- Не выполняйте git pull в репозиториях с переписанной историей (см. мета-репозиторий).
- Репозиторий называется open-vsc-claude; путь демо, заданный владельцем, — /open-vps-claude.

## Порядок выпуска

1. Запустите тесты (compile, test, test:vscode, test:web).
2. Повысьте версию в package.json и выполните npm run package.
3. gh release create vX.Y.Z с файлами .vsix и .sha256 (обновление проверяет контрольную сумму).
4. npm run build:demo, затем разместите webpage/ на VPS.
