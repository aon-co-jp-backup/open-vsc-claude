# Open VSC Claude

Расширение VS Code: выберите стек языка и фреймворка, посмотрите сгенерированный код, доработайте его с помощью Claude и сохраните как проект.

- Онлайн-демо: https://easy-web.tokyo/open-vps-claude/
- Исходный код: https://github.com/aon-co-jp/open-vsc-claude
- Лицензия: MIT

## Возможности

- Выбор подхода: GraphQL + WunderGraph Cosmo (без Node.js и REST), TypeScript + Node.js + REST или любой стек, описанный своими словами.
- Выбор фронтенда (HTML5+CSS3+JS, экспериментальный Rust+Leptos, TypeScript, React), БД (нет / SQLite / PostgreSQL), шлюза (Cosmo Router / RPoem / нет) и бэкенда (Python+FastAPI, Rust+Poem, Node.js+Express).
- Просмотр всех сгенерированных файлов с номерами строк; копирование или открытие в редакторе. При смене выбора предпросмотр обновляется сразу.
- «Сгенерировать / доработать с Claude» правит проект по вашему запросу (нужен ключ Anthropic API).
- Сохранение в папку (с подтверждением перезаписи) или, в браузерной демо, загрузка zip.
- Интерфейс и уведомления на английском, японском, китайском (упрощённом/традиционном) и корейском; проверка обновлений для ручной установки.

## Поддерживаемые платформы

Один чисто JavaScript-пакет, без нативного кода.

| Платформа | Как использовать |
| --- | --- |
| Windows / macOS / Linux | Расширение VS Code (настольное) |
| Android (phone, tablet) / iPhone / iPad | VS Code в браузере (vscode.dev / github.dev) с веб-расширением или браузерная демо на главном экране (PWA, работает офлайн) |
| * | Онлайн-демо: https://easy-web.tokyo/open-vps-claude/ |

## Использование

1. Выполните «Open VSC Claude: Open Stack Picker» в палитре команд.
2. Выберите стек — предпросмотр обновится сразу.
3. Для генерации с Claude загрузите ключ API («Load Anthropic API Key from a .txt file») и нажмите Ctrl+Enter.

## Примечания

- Сгенерированный код — отправная точка; перед использованием в продакшене проверьте, протестируйте и защитите его. Без гарантий.
- Генерация с Claude отправляет выбранный стек, файлы и запрос в Anthropic API; не включайте секреты и персональные данные.
- Ключи API, токены и закрытые ключи SSH храните в локальном .txt вне репозитория; не коммитьте и не вставляйте их в чат.
- Шлюз RPoem маршрутизирует только по корневым полям (запросы, смешивающие подграфы, отклоняются); Rust + Leptos — экспериментально.
- Полный текст примечаний на пяти языках показан в окне выбора и в README расширения.
